# UI Flows

## Add Artwork

1. Open `Add Artwork`.
2. Enter the title, type, series, year, size, status, location, and notes.
3. Save the artwork.
4. Open the artwork detail page and add the main image.

The form keeps extra metadata visually secondary so the normal path stays simple.

## Add A Custom Field

1. Open `Settings`.
2. Use `Add information field`.
3. Choose the field name and type.
4. The field appears on artwork forms under `Extra fields`.

The field is stored in Excel as structured custom-field data.

## Track Prints And Copies

1. Open `Editions`.
2. Select the artwork.
3. Enter the number of sale copies and practice/proof copies.
4. Generate the copies.
5. Update each copy's status, location, and notes as needed.

## Record A Sale Or Movement

1. Open `People & Sales`.
2. Add the gallery, buyer, seller, or collector if needed.
3. Record a sale, consignment, loan, gift, lost item, return, or movement.
4. The artwork or edition status updates from the transaction.

## Browse The Library

The `Library` screen is the everyday home screen. It shows artwork cards with images, titles, type, status, and location. Search and filters help find work without opening Excel.
